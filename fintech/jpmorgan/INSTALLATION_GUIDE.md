# JPMorgan Payments PDP MCP - Complete Installation Guide\n\n## 📋 Overview\n\nThe JPMorgan Payments Developer Portal MCP (Model Context Protocol) Server enables developers to:\n- Search JPMorgan payment API documentation\n- Read and convert documentation to markdown\n- Discover related content and resources\n- Integrate with AI agents and IDEs\n\n**Repository**: `jpmorgan-payments/pdp-mcp`\n**Language**: Python 3.10+\n**License**: Apache 2.0\n\n---\n\n## ⚙️ Prerequisites\n\nBefore installation, ensure you have:\n\n```bash\n# Check Python version (must be 3.10 or higher)\npython --version\n\n# Check pip is installed\npip --version\n\n# Check git is installed\ngit --version\n```\n\n**Required**:\n- ✅ Python 3.10 or newer\n- ✅ pip or uv package manager\n- ✅ Git\n- ✅ Node.js (for MCP Inspector testing - optional but recommended)\n\n**Optional for Corporate Networks**:\n- Proxy configuration (HTTP_PROXY/HTTPS_PROXY)\n\n---\n\n## 🚀 Installation Methods\n\n### Method 1: Quick Installation with pip (Recommended for Beginners)\n\n**Step 1**: Clone the repository\n```bash\ngit clone https://github.com/jpmorgan-payments/pdp-mcp.git\ncd pdp-mcp\ncd mcp-for-api-documentation\n```\n\n**Step 2**: Create a virtual environment\n```bash\n# On Windows\npython -m venv .venv\n.venv\\Scripts\\activate\n\n# On macOS/Linux\npython -m venv .venv\nsource .venv/bin/activate\n```\n\n**Step 3**: Install dependencies\n```bash\npip install --upgrade pip\npip install \"markdownify>=1.1.0\" \"mcp[cli]>=1.11.0\" \"pydantic>=2.10.6\" \"httpx>=0.27.0\" \"loguru>=0.7.0\" \"beautifulsoup4>=4.12.0\"\n```\n\n**Step 4**: Install the package in development mode\n```bash\npip install -e .\n```\n\n✅ **Installation Complete!** Proceed to [Testing](#-testing)\n\n---\n\n### Method 2: Installation with uv (Faster, Recommended)\n\n**Step 1**: Install uv\n```bash\npip install uv\n```\n\n**Step 2**: Clone and setup\n```bash\ngit clone https://github.com/jpmorgan-payments/pdp-mcp.git\ncd pdp-mcp/mcp-for-api-documentation\n\n# Create virtual environment with uv\nuv venv\n\n# Activate environment\n# Windows:\n.venv\\Scripts\\activate\n\n# macOS/Linux:\nsource .venv/bin/activate\n```\n\n**Step 3**: Install with uv\n```bash\nuv pip install -e .\n```\n\n✅ **Installation Complete!** Proceed to [Testing](#-testing)\n\n---\n\n### Method 3: Direct Installation from GitHub\n\n```bash\npip install git+https://github.com/jpmorgan-payments/pdp-mcp.git\n```\n\n---\n\n## 🧪 Testing\n\n### Option A: Run Standalone Server\n\n```bash\ncd mcp-for-api-documentation\npython -m jpmc.mcp_for_api_documentation.server\n```\n\n**Expected Output**:\n```\n[INFO] Starting MCP server...\n[INFO] Server initialized successfully\n[INFO] Ready for connections...\n```\n\n---\n\n### Option B: Test with MCP Inspector (Interactive Testing)\n\n**Prerequisites**: Node.js must be installed\n\n```bash\n# Install MCP Inspector globally\nnpx @modelcontextprotocol/inspector\n```\n\n**Then run**:\n\n**Using uv**:\n```bash\nnpx @modelcontextprotocol/inspector uv --directory <path-to-project> run jpmc.mcp_for_api_documentation\n```\n\n**Using python**:\n```bash\ncd mcp-for-api-documentation\nnpx @modelcontextprotocol/inspector python -m jpmc.mcp_for_api_documentation.server\n```\n\n**MCP Inspector Features**:\n- 🔍 Interactive tool exploration\n- 📊 Request/response visualization\n- 🐛 Debugging capabilities\n- 📝 API documentation browser\n\n---\n\n## 🔧 Configuration\n\n### Environment Variables\n\n| Variable | Purpose | Example |\n|----------|---------|----------|\n| `FASTMCP_LOG_LEVEL` | Logging verbosity | `DEBUG`, `INFO`, `WARNING`, `ERROR` |\n| `HTTP_PROXY` | Corporate proxy (HTTP) | `http://proxy.company.com:8080` |\n| `HTTPS_PROXY` | Corporate proxy (HTTPS) | `https://proxy.company.com:8443` |\n\n**Set environment variables**:\n\n```bash\n# macOS/Linux\nexport FASTMCP_LOG_LEVEL=DEBUG\nexport HTTP_PROXY=http://proxy.company.com:8080\n\n# Windows (PowerShell)\n$env:FASTMCP_LOG_LEVEL = \"DEBUG\"\n$env:HTTP_PROXY = \"http://proxy.company.com:8080\"\n\n# Windows (Command Prompt)\nset FASTMCP_LOG_LEVEL=DEBUG\nset HTTP_PROXY=http://proxy.company.com:8080\n```\n\n### IDE/AI Integration Configuration\n\n#### GitHub Copilot / VS Code\n\n1. Open VS Code settings (Ctrl+Shift+P)\n2. Search for \"MCP\"\n3. Add to `settings.json`:\n\n```json\n{\n  \"mcpServers\": {\n    \"jpmc.mcp_for_api_documentation\": {\n      \"command\": \"python\",\n      \"args\": [\n        \"-m\",\n        \"jpmc.mcp_for_api_documentation.server\"\n      ],\n      \"cwd\": \"/path/to/mcp-for-api-documentation\",\n      \"env\": {\n        \"FASTMCP_LOG_LEVEL\": \"ERROR\",\n        \"HTTP_PROXY\": \"http://proxy.company.com:8080\"\n      }\n    }\n  }\n}\n```\n\n#### Using uv (Recommended)\n\n```json\n{\n  \"mcpServers\": {\n    \"jpmc.mcp_for_api_documentation\": {\n      \"command\": \"uv\",\n      \"args\": [\n        \"--directory\",\n        \"/absolute/path/to/mcp-for-api-documentation\",\n        \"run\",\n        \"jpmc.mcp_for_api_documentation\"\n      ],\n      \"env\": {\n        \"FASTMCP_LOG_LEVEL\": \"ERROR\"\n      }\n    }\n  }\n}\n```\n\n#### IntelliJ IDEA\n\n1. Go to Settings → Tools → MCP\n2. Click \"+\" to add new MCP Server\n3. Configure with same settings as above\n\n---\n\n## 📚 Available Tools\n\nOnce installed, you have access to three tools:\n\n### 1. 🔍 search_documentation\n\nSearch across JPMorgan payment APIs.\n\n```python\nSearch Parameters:\n- search_phrase: str    # What to search for\n- limit: int (1-50)     # Max results (default: 10)\n\nReturns: List of matching documents with metadata\n```\n\n**Example**:\n```\n\"Search for checkout session documentation\"\n\"Find payment method documentation\"\n\"Look up webhook documentation\"\n```\n\n---\n\n### 2. 📖 read_documentation\n\nFetch and convert documentation to markdown.\n\n```python\nParameters:\n- url: str    # Documentation page URL\n\nReturns: Markdown-formatted content\n```\n\n**Example**:\n```\n\"Read the checkout implementation guide\"\n\"Get the API reference for payment sessions\"\n```\n\n---\n\n### 3. 🔗 related\n\nDiscover related documentation.\n\n```python\nParameters:\n- url: str    # Documentation page URL\n\nReturns: List of related document recommendations\n```\n\n**Example**:\n```\n\"Show related pages to the checkout documentation\"\n\"Find similar payment integration guides\"\n```\n\n---\n\n## 🧪 Development Setup\n\n### For Contributors\n\n```bash\n# Clone and setup\ngit clone mcp-for-api-documentation directory\ncd mcp-for-api-documentation\n\n# Reinstall with editable mode\npip install -e .\n\n# Verify installation\npython -c \"import jpmc; HTTPS_PROXY=https://proxy.company.com:8443\n\n# Reinstall packages\npip install --no-cache-dir -e .\n\n# Test server\npython -m jpmc.mcp_for_api_documentation.server\n```\n\n---\n\n### Issue 4: Port Already in Use\n\n```bash\n# Find and kill process using port\n# On macOS/Linux\nlsof -i :8000\nkill -9 <PID>\n\n# On Windows\nnetstat -ano | findstr :8000\ntaskkill /PID <PID> /F\n```\n\n---\n\n### Issue 5: MCP Inspector Not Working\n\n```bash\n# Ensure Node.js is installed\nnode --version\n\n# Update npm\nnpm install -g npm@latest\n\n# Clear npm cache\nnpm cache clean --force\n\n# Try inspector
